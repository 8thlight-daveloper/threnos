# Images

The Threnos mark and wordmark, as SVG.

| File | Use on |
| -- | -- |
| `threnos-lockup.svg` | Light backgrounds. Mark in color, name in charcoal |
| `threnos-lockup-dark.svg` | Dark backgrounds. Mark in color, name in near-white |
| `threnos-lockup-black.svg` | Light backgrounds, one color |
| `threnos-lockup-white.svg` | Dark backgrounds, one color |
| `threnos.svg` | Mark alone, in color |
| `threnos-black.svg` | Mark alone, light backgrounds, one color |
| `threnos-white.svg` | Mark alone, dark backgrounds, one color |
| `threnos-wordmark-black.svg` | Name alone, light backgrounds, one color |
| `threnos-wordmark-white.svg` | Name alone, dark backgrounds, one color |

Set one dimension when you place a file. Both the mark and the lockup keep
their proportions only if the other dimension follows.

## Typeface

The name is set in Montserrat SemiBold, converted to outlines, so the files do
not depend on an installed font. The top of the `h` is cut to the capital
height, so it lines up with the `T`. Montserrat is licensed under the
[SIL Open Font License 1.1](https://openfontlicense.org/open-font-license-official-text/).
